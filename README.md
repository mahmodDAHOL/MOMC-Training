# بوابة برنامج تدريب الخريجين الجدد — `momc_training`

تطبيق Frappe يُثبَّت على ERPNext v15. يدير برنامج تدريب الخريجين كاملاً، من التسجيل إلى قرار القبول:

| الجزء | ما يقدمه |
| --- | --- |
| بوابة المتقدم `/training` | حساب مستقل بالبريد وكلمة مرور، تأكيد البريد برمز، استعادة كلمة المرور |
| ملف التقديم | 5 خطوات: الهوية ← البيانات الشخصية ← المؤهل والمسار ← الصورة والشهادة ← المراجعة |
| قراءة الهوية آلياً | يرفع المتقدم وجهي الهوية السورية، فيقرأ النظام الحقول ويملأ النموذج ليراجعها المتقدم |
| امتحان القبول | 50 سؤالاً (قدرات ذهنية + المسارات الثلاثة)، مؤقت يفرضه الخادم، حفظ فوري لكل إجابة، تصحيح آلي، واقتراح مسار |
| داخل ERPNext | مساحة عمل «تدريب الخريجين»، ملف كل متقدم مع صوره، زرّا قبول/رفض مع إشعار بالبريد، بنك أسئلة قابل للتعديل، وإعدادات |

## التثبيت

```bash
# 1) محرك قراءة الهوية (مرة واحدة على الخادم)
sudo apt install tesseract-ocr tesseract-ocr-ara
tesseract --list-langs   # يجب أن تظهر ara

# 2) التطبيق
cd ~/frappe-bench
bench get-app /path/to/momc_training      # أو رابط المستودع الداخلي
bench --site erp.momc.gov.sy install-app momc_training
bench build --app momc_training
bench restart
```

بعد التثبيت:

1. أنشئ **Email Account** صادراً افتراضياً في ERPNext، فرموز التأكيد ترسَل بالبريد.
2. افتح **إعدادات برنامج التدريب** واضبط مدة الامتحان والحدود الدنيا وبريد التواصل ونص سياسة البيانات.
3. امنح موظفي اللجنة دور **Training Manager**.
4. شارك الرابط `https://<الموقع>/training`.

## الترقية من الإصدار 1.0.0

```bash
cd ~/frappe-bench
# استبدل مجلد apps/momc_training بالنسخة الجديدة ثم:
bench --site erp.momc.gov.sy migrate        # يحذف مساحة العمل القديمة المعطوبة تلقائياً
bench build --app momc_training
bench --site erp.momc.gov.sy clear-cache
bench restart
```

ثم حدّث المتصفح بـ Ctrl+Shift+R.

**ما الذي أُصلح في 1.0.1:**
- **«Page تدريب-الخريجين not found»:** كان اسم مساحة العمل الداخلي `Graduate Training` وعنوانها عربياً. Frappe يبني رابط القائمة من العنوان، ويبحث عن الصفحة بالاسم، فلا يجدها. صار الاسم والعنوان «تدريب الخريجين»، وبطاقات الأرقام تظهر الآن.
- **البوابة بلا تنسيق:** صارت أنماط البوابة وسكربتها وشعارها مضمّنة في الصفحة نفسها. لم تعد تعتمد على مجلد `/assets`، فتعمل حتى لو لم يُنفَّذ `bench build`.
- **الهوية البصرية:** اعتُمدت ألوان الوزارة: الأخضر الداكن `#054239`، وأخضر الشعار `#126E70`، والبرونزي `#988561`. طُبّقت على البوابة والرسائل، وعلى شاشات البرنامج داخل ERPNext: مساحة العمل، والقوائم، والنماذج. بقية وحدات ERPNext لم تتغير.

## قرارات تصميم تستحق المعرفة

- **حسابات المتقدمين مستقلة عن مستخدمي ERPNext.** لا يُنشأ لهم User، فلا يصلون إلى أي DocType آخر. كلمات المرور مخزنة بتجزئة pbkdf2_sha256 (مكتبة passlib نفسها التي يستخدمها Frappe). الجلسة رمز عشوائي في كوكي httpOnly وSameSite=Lax، ولا يخزَّن في Redis إلا بصمته. كل طلب يغيّر البيانات يحمل رمز CSRF إضافياً.
- **حماية من التخمين:** حدّ للطلبات لكل IP على كل نقطة دخول، وإيقاف الدخول 15 دقيقة بعد 5 محاولات خاطئة لنفس البريد، و5 محاولات فقط لكل رمز تأكيد.
- **الملفات خاصة (private).** تُعاد ترميز كل صورة إلى JPEG، فتُحذف بيانات EXIF ومنها الموقع الجغرافي، وتُرفض الملفات المزيفة. يُقبل PDF للشهادة فقط، ويُرفض إن احتوى محتوى نشطاً.
- **الإجابات الصحيحة لا تغادر الخادم.** ترتيب الأسئلة وترتيب الخيارات عشوائي لكل متقدم، والوقت يُحسب على الخادم. مهمة مجدولة كل 5 دقائق تسلّم الامتحانات التي انتهى وقتها والمتصفح مغلق.
- **القراءة الآلية اقتراح لا قرار.** يرى المتقدم الحقول المقروءة مظللة ويصححها. يسجّل النظام الحقول التي عدّلها في «حقول عدّلها المتقدم بعد القراءة الآلية»، لتعرف اللجنة ما يستحق التدقيق.

## قراءة الهوية: كيف تعمل وما حدودها

القارئ لا يعتمد على مواقع ثابتة في الصورة. يعمل على أي صورة هوية سورية بالخطوات التالية:

1. يجد البطاقة داخل الصورة ويسطّحها، ويعدّل الميلان حتى ±8°. يقلب الصورة المصوّرة بالطول أو المقلوبة.
2. يفصل الحبر عن خلفية الحماية بمرشّح يتكيّف مع الإضاءة ولون البطاقة.
3. **يبحث عن العناوين المطبوعة** (الاسم، النسبة، اسم الأب، الرقم الوطني، الأمانة، القيد…) بمطابقة تقريبية، ويقرأ القيمة المطبوعة بجانب كل عنوان أينما كانت.
4. يتعرّف على الوجه (أمامي أو خلفي) من العناوين نفسها، وينبّه المتقدم إن رفع الوجه في الخانة الخطأ.
5. يقرأ الأرقام بقارئين مستقلين (Tesseract ومصنّف أشكال الأرقام). لا تُعطى ثقة عالية إلا إذا اتفقا. يُصحَّح اسم المكان إلى أقرب محافظة أو مدينة سورية معروفة إن كان الخطأ حرفاً واحداً.
6. على البطاقات المهترئة التي لا تُقرأ عناوينها، يستعين بقارئ احتياطي يعتمد مواقع الصفوف المعتادة. يختار لكل حقل القراءة الأوثق، ويخفّض الثقة إن اختلف القارئان.

في البوابة يظهر كل حقل مقروء مظللاً. الحقل منخفض الثقة يظهر بلون برتقالي مع عبارة «القراءة غير مؤكدة، قارنها بالهوية حرفاً حرفاً».

**النتائج المقاسة:**

| الاختبار | النتيجة |
| --- | --- |
| الهوية الحقيقية المرفقة (مهترئة ومتشققة)، الوجه الأمامي | 7 من 7 حقول صحيحة |
| الهوية الحقيقية، الوجه الخلفي | الأمانة والجنس صحيحان؛ القيد غير مقروء |
| 60 بطاقة اصطناعية بخطوط **لم يُدرَّب عليها** القارئ، مع ميلان وإضاءة غير متساوية وضبابية وضغط JPEG | تحديد الوجه 120/120 · مكان الولادة 97% · الأمانة 90% · الجنس 90% · تاريخ الولادة 83% · الأسماء 52–67% · الرقم الوطني 62% |
| الرقم الوطني والتواريخ المقروءة خطأً بثقة عالية | 0 في كل الاختبارات |

الخلاصة: الأماكن والجنس والتواريخ تُقرأ غالباً. **الأسماء تحتاج مراجعة المتقدم في نحو نصف الحالات**، وأغلب أخطائها حرف واحد. لهذا تبقى القراءة اقتراحاً يؤكده المتقدم.

لرفع الدقة لاحقاً، اجمع 50–100 صورة هوية حقيقية بموافقة أصحابها، وقِس بها بالأداة `tools/ocr_benchmark.py`. لتوليد بطاقات اختبار: `python tools/synth_cards.py OUT 100`.
